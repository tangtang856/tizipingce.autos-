在查看机场的节点列表或官方介绍时，常常会遇到一堆看似高深莫测的技术名词：**IPLC、IEPL、BGP、公网中转、直连 VPS、Anycast**。

这些名词到底代表着什么含义？为什么 IPLC 节点通常价格更贵？不同类型的节点在实际使用体验中又有多大差别？本文为你彻底拆解。

## 一、四大主流机场节点架构图解与对比

### 1. IPLC（International Private Leased Circuit，国际私有租用线路）
- **架构原理**：两端物理光纤专线直连（如深圳直通香港、上海直通东京）。用户流量从国内入口服务器进入后，走的是运营商私有的跨境物理光缆内网。
- **最大优势**：**完全不经过中国公网防火墙（GFW）的审查与干扰**。因此无论敏感时期外界如何地动山摇，IPLC 专线都能保持 0% 丢包率与极低的稳定延迟。
- **缺点**：专线带宽租金极其昂贵，故采用纯 IPLC 的机场套餐价格普遍较高。

### 2. IEPL（International Ethernet Private Line，国际以太网专线）
- **架构原理**：与 IPLC 类似，也是一种点对点的企业级内网以太网物理专线。
- **与 IPLC 的区别**：IEPL 基于二层以太网技术，相比传统 IPLC 在拓扑调整和抖动控制上更现代化。对于普通用户来说，**IEPL 与 IPLC 在抗封锁、低延迟和稳定性上的表现几乎完全一致**，均属于第一梯队的高端网络。

### 3. BGP 隧道中继（Border Gateway Protocol）
- **架构原理**：国内入口采用 BGP 多线接入（自动适配电信、联通、移动、广电等各家宽带，保证无论用户本地使用什么宽带，连接入口延迟都极低），然后通过加密隧道跨境转发至境外落地机房。
- **优势**：性价比极高。带宽成本远低于物理专线，但在非极度恶劣管制期，其速度和延迟表现非常优异。
- **缺点**：跨境段本质上仍走公网出口，极端封锁期偶有端口被干扰风险。

### 4. 公网直连（Direct VPS）
- **架构原理**：用户的本地设备直接通过公网连接境外的 VPS 服务器，中间没有任何国内中继中转。
- **体验评价**：**体验最差的一类**。极易受到公网国际出口拥堵（晚高峰丢包飙升至 30%+）和 GFW 的主动探测封锁。目前仅见于极低价的劣质机场或早期自建节点。
