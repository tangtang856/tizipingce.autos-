当你在机场后台购买了服务后，可能会发现机场提供的订阅链接格式是传统的“V2Ray 单条链接”或旧版“SS 链接”，而你手机上使用的客户端是 **Clash** 或 **Surge**。

此时，你就需要借助一个中间工具将这串链接翻译成客户端看得懂的 YAML 或 Conf 格式，这个过程就叫做 **订阅转换 (Subconverter)**。

---

## 一、订阅转换的工作原理

订阅转换程序（通常基于开源项目 `tindy2013/subconverter`）扮演的是一个“数据格式翻译官”的角色：
1. **下载原始节点**：转换器服务器代你向机场订阅 URL 发起 GET 请求，下载原始的 Base64 节点数据；
2. **解码与解析**：将包含服务器 IP、端口、UUID、密码、加密方式的字符串解析为结构化数据对象；
3. **套用分流规则模板**：注入预设的分流规则（如 ACL4SSR 或 Loyalsoldier 规则集，区分国内直连与海外代理）；
4. **生成目标配置文件**：输出格式规范的 Clash YAML 文件或 Surge 配置文件供客户端读取。

---

## 二、使用公共第三方订阅转换的安全隐患

许多新手由于图省事，在网上随意搜索并使用免费的公共订阅转换网站，这存在极其严重的**数据被截获风险**：
- **Token 泄露与流量被盗刷**：恶意搭建者可以在后台 Nginx 访问日志中完整抓取你提交的订阅 URL，随后提取你的节点并批量盗用你的套餐流量；
- **注入恶意后门规则**：极少数不良转换器可能会在生成的规则中，将特定银行或邮箱域名的流量劫持重定向至其控制的中途节点进行嗅探。

---

## 三、安全使用建议
1. **优先使用机场官方原生适配**：现代正规机场控制台几乎都已原生集成了 Clash、Shadowrocket、Surge 的一键转换导出，无需第三方转换；
2. **本地客户端自带转换**：使用 Clash Verge Rev 或 Sing-box 等现代客户端，其内部自带转换解析引擎；
3. **自建 Docker 转换后端**：如果确实需要个性化深度定制分流规则，推荐在本地电脑或私有 NAS 上通过 Docker 部署一套完全属于自己的私有 subconverter 服务。
