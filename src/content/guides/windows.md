在 Windows 平台上，过去常用的 Clash for Windows 已于 2023 年底停止维护。目前开源社区最推荐、更新活跃且采用最新 Clash.Meta (Mihomo) 内核的客户端是 **Clash Verge Rev**。

本文将手把手带你完成从零到一的客户端安装与机场节点订阅导入。

---

## 一、前期准备工作

在开始配置前，请确保具备以下两项条件：
1. **一个有效的机场节点订阅链接**：如果您尚未拥有订阅，可参考本站的 [高性价比机场排行榜](/ranking/value/) 或 [新手入门友好机场推荐](/recommend/beginner/) 购买适合的套餐并复制订阅 URL。
2. **正确校准系统时间**：Windows 右下角时间必须与北京时间/网络授时严格一致（误差在 1 分钟以内），否则 TLS 握手会失败导致节点全部报“超时 (Timeout)”。

---

## 二、下载与安装 Clash Verge Rev

1. **获取安装包**：前往官方 GitHub Releases 仓库（建议下载最新稳定版本的 `Clash.Verge_x.x.x_x64-setup.exe` 安装包）。
2. **运行安装向导**：双击运行安装程序，按照提示选择安装路径，建议安装在无中文、无特殊符号的磁盘路径中。
3. **语言设置**：首次启动程序默认为英文，点击左侧菜单栏底部的 **Settings**（设置），找到 **Language** 切换为 **简体中文**。

---

## 三、导入机场订阅链接

### 步骤 1：获取订阅链接
登录您的机场后台用户中心，找到“我的订阅”或“一键订阅”，选择 **复制 Clash 订阅地址**。

### 步骤 2：在客户端配置中粘贴
1. 打开 Clash Verge Rev，在左侧导航栏点击 **配置 (Profiles)**。
2. 在右上方的文本输入框中粘贴刚才复制的订阅链接。
3. 点击右侧的 **导入 (Import)** 按钮。
4. 客户端将自动发起 HTTP 请求下载节点配置文件。下载成功后，列表中会出现该配置文件的名称卡片。
5. **单击该配置卡片**，使其左侧或边框亮起（代表激活为当前使用配置）。

---

## 四、开启代理与选择节点

1. **切换代理模式**：点击左侧导航栏的 **代理 (Proxies)**。
   - 顶部提供 **规则 (Rule)**、**全局 (Global)**、**直连 (Direct)** 三种模式。
   - **强烈推荐选择【规则 (Rule)】模式**：该模式下国内网站（百度、淘宝、微信等）直连不消耗翻墙流量，国外受限网站（Google、YouTube、ChatGPT）自动走代理节点。
2. **选择节点**：在节点分组中展开节点列表，点击右上角闪电图标可进行批量测速，选择一个延迟较低（如绿色 100ms-250ms）的节点。
3. **开启系统代理**：点击左侧菜单栏的 **设置 (Settings)**，找到 **系统代理 (System Proxy)** 开关并打开。此时浏览器即可直接访问 Google 等海外网站。

---

## 五、Windows 常见报错排查

### 1. 节点全部显示 Timeout / 超时
- **解决方案**：打开 Windows“日期和时间设置”，点击“立即同步”。90% 的突然全部超时均为系统时间偏差引起。

### 2. 浏览器打不开外网，但 Telegram 等软件正常
- **解决方案**：检查浏览器安装的代理插件（如 SwitchyOmega）是否产生规则冲突。将插件设置为“使用系统代理”或暂时禁用。

### 3. UWP 应用（如 Windows 商店、Copilot）无法联网
- **解决方案**：Clash Verge Rev 设置中集成了“UWP 工具 (Windows Loopback)”，点击开启“应用回环代理”并勾选相关 UWP 应用即可。
